Main Topics Covered 

Day 1: Introduction to Open-Source ASIC Design 

Basics of how computers execute software and hardware concepts. 

Introduction to: 

QFN-48 packages, chips, dies, cores, pads, and IPs. 

RISC-V architecture. 

SoC design concepts. 

Open-source digital ASIC design flow. 

Understanding the RTL-to-GDSII flow using OpenLANE. 

Running synthesis and reviewing synthesis results. 

Exploring OpenLANE project structure and workflow. [VSDIAT]

Chip floorplanning concepts: 

Utilization factor. 

Aspect ratio. 

Power planning. 

Pin placement. 

Decoupling capacitors. 

Placement optimization techniques. 

Library binding and characterization. 

Timing concepts: 

Timing thresholds. 

Propagation delay. 

Transition time. [VSDIAT] 

Day 3: Standard Cell Design and Characterization 

CMOS inverter design using ngspice. 

SPICE deck creation and simulation. 

CMOS fabrication process: 

N-well/P-well formation. 

Gate creation. 

Source/drain formation. 

Metal layers and interconnects. 

Layout design in Magic. 

DRC (Design Rule Check) exercises. 

Characterizing cells using Sky130 technology files. [VSDIAT] 

Day 4: Timing Analysis and Clock Tree Synthesis 

Timing modeling using delay tables. 

Creating LEF files from layouts. 

Using OpenSTA for timing analysis. 

Setup and hold time analysis. 

Clock uncertainty and jitter. 

Clock Tree Synthesis (CTS) with TritonCTS. 

Signal integrity and crosstalk considerations. [VSDIAT] 

Day 5: Routing and Final RTL-to-GDS Steps 

Routing algorithms, including Lee's Maze Routing. 

Design Rule Checking (DRC). 

Building Power Distribution Networks (PDN). 

Global and detailed routing using TritonRoute. 

Handling routing connectivity and topology. 

Final post-route outputs and verification steps. [VSDIAT] 

Overall Takeaway 

The course provides a complete end-to-end ASIC design flow, starting from digital design fundamentals and RTL, progressing through synthesis, floorplanning, placement, standard-cell design, timing analysis, clock-tree synthesis, routing, DRC verification, and ending with final GDS generation using the OpenLANE + Sky130 open-source toolchain.
